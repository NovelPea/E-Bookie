# E-Bookie

E-Bookie is a simple, single-file web app for discovering, creating, and reading books. It supports community-created (UGC) books and real books, with a built-in bookshelf, search, sorting, and a reader view.

## Features

- Browse featured, community, real, and personally created books
- Search books by title, author, or genre
- Sort books by title or author
- Create and read books in the browser
- Save your books in browser storage with `localStorage`
- Responsive layout for desktop and mobile
- No frameworks or dependencies required

## Getting started

1. Save the website code as `index.html`.
2. Open `index.html` in a modern web browser.
3. Select **Create a book** to add your own title, author, genre, description, and text.

Your created books are saved locally in the browser you used. They are not uploaded or shared with other users.
